# gpulse - a genetic algorithm based control pulse optimiser

## Installation
To install gpulse clone this repository with `git clone https://github.com/madhavkrishnan/gpulse.git` and inside the gpulse repository run

```
pip install -e .
```

The `-e` flag is to install the package in editable mode so that any changes you make to the code will be reflected in the package (after reloading).

## Usage
Example ipython notebooks can be found [here](https://github.com/madhavkrishnan/gpulse/tree/master/example). If you would like to try the code out without installing the package use this [Colab notebook](https://colab.research.google.com/drive/1qzdeQiE99qgSZbiJyHmq6HKRWQqeA4QO?usp=sharing)
